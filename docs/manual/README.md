## เริ่มใช้วันแรกต้องรู้ 10 ข้อ

1. **เข้าระบบที่ https://osoth.com** ด้วยบัญชีที่เจ้าของสร้างให้ — เข้าครั้งแรกระบบจะบังคับตั้งรหัสผ่านใหม่ก่อน ถึงจะใช้งานต่อได้
2. **เมนูหายไม่ใช่ระบบเสีย** — แต่ละตำแหน่งเห็นเมนูไม่เท่ากันตามสิทธิ์ ชื่อบทบาทของคุณอยู่มุมขวาบนของจอ (ใครกดอะไรได้บ้าง ดูตารางในบทที่ 3)
3. **งานทุกเคสวิ่งเส้นทางเดียว**: **ปฏิทิน (จองคิว)** → **ปฏิทิน (รับลูกค้า)** → **OPD / หน้าห้อง** → ปิดเคส — ทำตามลำดับนี้เสมอ
4. **ลูกค้าใหม่กรอกประวัติ + เซ็นชื่อครั้งเดียว** ตอนมาถึงร้านครั้งแรก ระบบออกเลขประจำตัว (HN) ให้ — รอบหน้าหรือซื้อคอร์สใหม่ก็ใช้ประวัติเดิม ไม่ต้องกรอกซ้ำ (ส่วนใบยินยอมกับประวัติสุขภาพประจำคอร์ส เป็นคนละใบกัน — ดูข้อ 7)
5. **ค่าคอร์สจ่ายเต็มจำนวนก่อนทำหัตถการ — ระบบไม่รับผ่อน** แต่แบ่งจ่ายหลายช่องทางในบิลเดียวได้ (เงินสด/โอน/บัตร/หักมัดจำ) ขอแค่รวมกันเท่ายอดพอดี
6. **มัดจำถูกริบอัตโนมัติทันทีที่กดปุ่ม "ไม่มาตามนัด"** — ลูกค้าโทรมาขอเลื่อน ให้กด **เลื่อนนัด** (มัดจำติดไปกับคิวเดิม) อย่ากดไม่มาตามนัดเด็ดขาด
7. **ก่อนปิดเคสต้องครบ 4 อย่าง**: วัดตัวแล้ว · จ่ายครบแล้ว · สต๊อกยาพอ · ใบยินยอมเซ็นแล้ว (ครั้งแรกของคอร์สเพิ่มประวัติสุขภาพอีกหนึ่งใบ) — ขาดข้อไหน ปุ่มปิดเคสจะกดไม่ได้ · ใบยินยอมต้องเซ็นใหม่ทุกครั้งที่ทำ เพราะเป็นหลักฐานยินยอมต่อการทำหัตถการแต่ละครั้ง ไม่ใช่ต่อคอร์ส
8. **คนกดปิดเคสได้มีแค่แอดมินกับเจ้าของ** — กดครั้งเดียวระบบจัดการให้หมด: ตัดสต๊อกยา นับครั้งคอร์ส คิดค่ามือ/คอมให้พนักงาน ไม่ต้องคีย์อะไรเพิ่ม
9. **รับเงินเมื่อไหร่ ใบเสร็จออกทันที** เลขที่รันอัตโนมัติ (เช่น RC2569-00001) — ทำบิลผิดห้ามแก้เอง ต้องให้ **เจ้าของ** ยกเลิกใบเสร็จพร้อมกรอกเหตุผลเท่านั้น เลขที่เดิมจะยังอยู่ในระบบตามหลักบัญชี
10. **เข้างานอย่าลืมกดลงเวลา** ที่เมนู **ลงเวลาเข้างาน** (ทั้งเข้าและออก) — ค่ามือ/คอมของตัวเองเปิดดูได้ที่ **รายได้ของฉัน** ระบบคิดให้เอง ไม่ต้องจดเอง
