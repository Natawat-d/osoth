## เริ่มใช้วันแรกต้องรู้ 10 ข้อ

1. **เข้าระบบที่ https://osoth.com** ด้วยชื่อผู้ใช้ที่เจ้าของตั้งให้ — เข้าครั้งแรกต้องตั้งรหัสผ่านใหม่ก่อน
2. **บทบาทของคุณกำหนดเมนูที่เห็น** — แต่ละตำแหน่งเห็นเมนูไม่เท่ากัน ชื่อบทบาทแสดงอยู่มุมขวาบนของจอ (ดูตารางสิทธิ์ในบทที่ 3)
3. **เส้นทางงานหลักของร้านมี 4 ป้าย**: **ปฏิทิน (จองคิว)** → **ปฏิทิน (รับลูกค้า)** → **OPD / หน้าห้อง** → ปิดเคส — ทำตามลำดับนี้เสมอ
4. **ลูกค้าใหม่กรอกประวัติ + เซ็นชื่อครั้งเดียว** ตอนมาถึงร้านครั้งแรก ระบบสร้าง HN ให้ — รอบต่อไปไม่ต้องกรอกใหม่ แม้คนละคอร์ส
5. **ค่าคอร์สจ่ายเต็มจำนวนก่อนทำหัตถการ — ไม่มีผ่อน** แต่แยกจ่ายหลายช่องทางได้ (เงินสด/โอน/บัตร/หักมัดจำ) ขอแค่รวมกันเท่ายอดพอดี
6. **มัดจำถูกริบอัตโนมัติเมื่อกด "ไม่มาตามนัด"** — ถ้าลูกค้าโทรมาขอเลื่อน ให้กด **เลื่อนนัด** (มัดจำติดไปกับคิวเดิม) อย่ากดไม่มาตามนัด
7. **ก่อนปิดเคสต้องครบ**: วัดตัว ✓ ชำระครบ ✓ สต๊อกพอ ✓ ใบยินยอมเซ็นแล้ว ✓ (และครั้งแรกของคอร์สต้องมีประวัติสุขภาพ ✓) — ขาดข้อใดข้อหนึ่ง ปุ่มปิดเคสจะกดไม่ได้
8. **ปิดเคสได้เฉพาะแอดมินกับเจ้าของ** — กดครั้งเดียวระบบตัดสต๊อกยา นับครั้งคอร์ส และคิดค่ามือ/คอมให้พนักงานอัตโนมัติ
9. **ใบเสร็จออกอัตโนมัติทุกครั้งที่รับเงิน** (เลขรัน RC ต่อเนื่อง) — ทำบิลผิดต้องให้ **เจ้าของ** เป็นคนยกเลิกใบเสร็จเท่านั้น และต้องกรอกเหตุผลทุกครั้ง
10. **พนักงานกดลงเวลาเข้า–ออกงานทุกวัน** ที่เมนู **ลงเวลาเข้างาน** และดูค่ามือ/คอมของตัวเองได้ที่ **รายได้ของฉัน** — ระบบคิดให้อัตโนมัติ ไม่ต้องจดเอง

## บัญชีทดสอบ (ระบบฝึกใช้งาน / demo)
