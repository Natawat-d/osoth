# บทที่ 3 — บทบาทและสิทธิ์: ใครทำอะไรได้บ้าง

ระบบ OSOTH แบ่งผู้ใช้เป็น **5 บทบาท** แต่ละคนเห็นเมนูไม่เหมือนกัน และทำรายการได้ไม่เท่ากัน อยากรู้ว่าบัญชีตัวเองเป็นบทบาทไหน ดูที่**มุมขวาบนของจอ ใต้ชื่อเล่นของคุณ**

| บทบาทในระบบ | ป้ายที่แสดงบนจอ | หน้าที่หลัก |
|---|---|---|
| เจ้าของ (owner) | **เจ้าของระบบ** | บริหารทั้งระบบ — ตั้งค่า คลัง การเงิน เงินเดือน HR |
| แอดมิน | **แอดมิน (จอง/รับ/OPD)** | จองคิว รับลูกค้า ทำ OPD ครบวงจร ปิดเคส อนุมัติลา |
| เซลส์ | **ฝ่ายขาย** | จองคิว รับลูกค้า ขายคอร์ส |
| หมอ | **แพทย์** | ทำหัตถการในคิวของตัวเอง |
| BT | **ผู้ช่วยหัตถการ** | ทำหัตถการขั้น BT ในคิวที่ได้รับมอบ |

> สิทธิ์ทั้งหมด "ล็อกที่เซิร์ฟเวอร์" ไม่ใช่แค่ซ่อนเมนู — ต่อให้พยายามทำรายการข้ามสิทธิ์ ระบบจะปฏิเสธและขึ้นข้อความแจ้ง เช่น "เฉพาะเจ้าของระบบเท่านั้น" และถ้าเปิดหน้าที่ไม่มีสิทธิ์ จะเจอหน้า **ไม่มีสิทธิ์เข้าถึง** พร้อมปุ่ม **กลับหน้างาน**

\** เมนูกลุ่ม "บุคคล" (ลงเวลา / ลางาน / รายได้ของฉัน) เป็นเมนูฝั่งพนักงาน — เจ้าของไม่มีเมนูนี้ แต่ดูข้อมูลพนักงานทุกคนได้จากเมนู **บุคคล (HR)** แทน ส่วนหน้าจออนุมัติใบลาอยู่ในเมนู **ลางาน** คนที่กดอนุมัติหน้างานจริงจึงเป็น **แอดมิน** (ฝั่งเซิร์ฟเวอร์เปิดสิทธิ์ให้ทั้งแอดมินและเจ้าของ)

> ⚠️ กฎที่ต้องจำให้ขึ้นใจ
> - **ปรับราคาหน้างาน** ทำได้เฉพาะ **แอดมินกับเจ้าของ** — เซลส์ขายตามราคาตั้ง/ราคาโปรเท่านั้น ถ้าเซลส์พยายามใส่ราคาปรับเอง ระบบจะฟ้อง "ปรับราคาหน้างานได้เฉพาะ admin/เจ้าของ"
> - **ยกเลิกใบเสร็จ · ล็อกงวดบัญชี · เงินเดือน** เป็นอำนาจ **เจ้าของเท่านั้น** — แม้แต่แอดมินก็ทำไม่ได้ (ระบบจะขึ้น "เฉพาะเจ้าของระบบเท่านั้น")
> - **ปิดเคส** ทำได้เฉพาะ **แอดมินกับเจ้าของ** — หมอ/BT บันทึกหัตถการเสร็จแล้วส่งต่อให้แอดมินเป็นคนปิด

## เจ้าของ (เจ้าของระบบ)

![เมนูของเจ้าของ](img/03-sidebar-owner.png)

เจ้าของเห็นเมนูมากที่สุด แบ่งเป็น 3 กลุ่ม

- **ภาพรวม** — **Dashboard** (สรุปกิจการ มีเฉพาะเจ้าของ) และ **การแจ้งเตือน**
- **ผู้บริหาร** — **ตั้งค่าธุรกิจ (Setup)** · **คลังสินค้า (Inventory)** · **การเงิน/บัญชี (Finance)** · **บุคคล (HR)** — ทั้ง 4 เมนูนี้มีเฉพาะเจ้าของ
- **งานหน้าร้าน** — **ปฏิทิน (จองคิว)** · **ปฏิทิน (รับลูกค้า)** · **OPD / หน้าห้อง** · **ลูกค้า (HN)** — เจ้าของลงมาช่วยงานหน้าร้านได้ทุกอย่าง

**หนึ่งวันของเจ้าของ** — เช้าเปิด **Dashboard** กวาดตาดูยอดขายกับคิววันนี้ก่อนใคร มีหลายสาขาก็สลับสาขาดูได้จากจุดเดียว (เจ้าของเป็นคนเดียวที่สลับสาขาได้ — พนักงานเห็นเฉพาะสาขาตัวเอง) ระหว่างวันถ้าหน้าร้านมือไม่พอ เจ้าของลงไปช่วยจอง รับลูกค้า หรือทำ OPD ได้ทุกจุด เย็นเข้า **การเงิน/บัญชี (Finance)** ตรวจปิดยอดวัน สิ้นเดือนทำเงินเดือนที่ **บุคคล (HR)** แล้วกลับมาล็อกงวดบัญชีที่ Finance เพื่อกันใครแก้ตัวเลขย้อนหลัง

วันไหนมีใบเสร็จออกผิดหรือลูกค้าขอคืน เจ้าของเป็นคนเดียวที่กด **ยกเลิกใบเสร็จ** ได้ และระบบบังคับกรอกเหตุผลทุกครั้ง — เลขใบเสร็จไม่หายไปไหน เพื่อให้ตรวจย้อนหลังได้เสมอว่าใครยกเลิกอะไรเพราะอะไร

> เจ้าของจะไม่เห็นเมนูกลุ่ม "บุคคล" (ลงเวลา/ลางาน/รายได้ของฉัน) เพราะเป็นเมนูของพนักงาน — ถ้าเปิดหน้านั้นตรง ๆ จะเจอ "ไม่มีสิทธิ์เข้าถึง" ซึ่งเป็นเรื่องปกติ ไม่ใช่ระบบพัง

## แอดมิน (จอง/รับ/OPD)

![เมนูของแอดมิน](img/03-sidebar-admin.png)

แอดมินคือ "แม่งาน" ของหน้าร้าน — ทำได้ครบตั้งแต่จองจนปิดเคส

- **งานหน้าร้าน** — **ปฏิทิน (จองคิว)** · **ปฏิทิน (รับลูกค้า)** · **OPD / หน้าห้อง** · **ลูกค้า (HN)**
- **บุคคล** — **ลงเวลาเข้างาน** · **ลางาน** · **รายได้ของฉัน**

**หนึ่งวันของแอดมิน** — เช้าเปิด **ปฏิทิน (รับลูกค้า)** ไล่รับลูกค้าตามคิวที่จองไว้ เจอลูกค้าใหม่ก็กรอกประวัติ + สร้าง HN ให้ตรงหน้ารับลูกค้านั้นเลย แล้วเปิดเคสเข้า **OPD / หน้าห้อง** — วัดตัว ขายคอร์ส รับเงิน มอบหมายหมอกับ BT พอหัตถการเสร็จ แอดมินเป็นคนกด **ปิดเคส** (หมอ/BT ปิดเองไม่ได้ ทุกเคสต้องผ่านมือแอดมินเพื่อเช็กว่าเงินครบ ใบยินยอมครบ) ระหว่างวันโทรศัพท์ดังตลอด — ลูกค้าโทรมาจองหรือขอเลื่อนนัด ก็สลับไปจัดการที่ **ปฏิทิน (จองคิว)** ได้เลยไม่ต้องรอใคร

งานที่มีแค่แอดมิน (กับเจ้าของ) ทำได้

1. **ปรับราคาหน้างาน** — ลูกค้าต่อรองราคา หรือมีส่วนลดพิเศษ ตอนขายคอร์สใน OPD จะมีช่อง **ปรับราคาหน้างาน** ให้กรอก (เซลส์ไม่เห็นช่องนี้)
2. **อนุมัติใบลา** — เปิดเมนู **ลางาน** กดแท็บ **รออนุมัติ** จะเห็นคำขอลาของพนักงานทุกคน กด **อนุมัติ** หรือ **ไม่อนุมัติ** ได้เลย (แท็บ **ขาดงานรายวัน** และ **สรุปการลา** ก็เห็นเฉพาะแอดมิน)

![หน้าลางานของแอดมิน มีแท็บ รออนุมัติ](img/03-leaves-admin-approve.png)

> ⚠️ แอดมินทำเรื่องเงิน "หน้าร้าน" ได้ทั้งหมด แต่เรื่อง "หลังบ้าน" ทำไม่ได้ — ยกเลิกใบเสร็จ คลังสินค้า การเงิน/บัญชี และเงินเดือน เป็นของเจ้าของเท่านั้น

## เซลส์ (ฝ่ายขาย)

![เมนูของเซลส์](img/03-sidebar-sale.png)

เซลส์ทำงานเหมือนแอดมินในส่วนจอง/รับ/ขาย แต่ **ไม่มีเมนู OPD / หน้าห้อง**

- **งานหน้าร้าน** — **ปฏิทิน (จองคิว)** · **ปฏิทิน (รับลูกค้า)** · **ลูกค้า (HN)**
- **บุคคล** — **ลงเวลาเข้างาน** · **ลางาน** · **รายได้ของฉัน**

**หนึ่งวันของเซลส์** — รับสายลูกค้ากับตอบแชทเป็นงานหลัก ลูกค้าตกลงเมื่อไรก็ลงจองที่ **ปฏิทิน (จองคิว)** ขายคอร์สและรับมัดจำได้เลยตอนจอง ไม่ต้องรอลูกค้ามาถึงร้าน พอลูกค้ามาจริงก็ช่วยรับที่ **ปฏิทิน (รับลูกค้า)** สร้าง HN ให้ลูกค้าใหม่ แล้วส่งเคสต่อให้แอดมินทำ OPD สิ้นวันเปิด **รายได้ของฉัน** ดูค่าคอมจากยอดที่ขายได้ — ยอดวิ่งเข้าอัตโนมัติ ไม่ต้องจดเอง

> ⚠️ เซลส์ขายตามราคาตั้ง/ราคาโปรเท่านั้น — **ปรับราคาหน้างานไม่ได้** ลูกค้าต่อรองราคาเมื่อไร อย่ารับปากเอง ให้ส่งต่อแอดมินหรือเจ้าของ

## หมอ (แพทย์)

![เมนูของหมอ](img/03-sidebar-doctor.png)

- **งานหน้าร้าน** — **OPD / หน้าห้อง** (เมนูหน้าร้านเมนูเดียวของหมอ)
- **บุคคล** — **ลงเวลาเข้างาน** · **ลางาน** · **รายได้ของฉัน**

**หนึ่งวันของหมอ** — เปิด **OPD / หน้าห้อง** จะเห็น**เฉพาะคิวที่มอบหมายให้ตัวเอง** (คิวของหมอท่านอื่นไม่ขึ้น) ลูกค้าพร้อมเมื่อไรก็เข้าเคส ทำหัตถการในการ์ด **ขั้นแพทย์** เสร็จแล้วกด **บันทึก + เสร็จขั้นแพทย์** — ถ้าปุ่มกดไม่ได้และขึ้น "ต้องชำระเงินก่อน" แปลว่าลูกค้ายังจ่ายไม่ครบ ส่งเรื่องกลับให้แอดมินก่อน หรือถ้าขึ้น "ทำขั้น BT ก่อน" ก็รอ BT ทำขั้นของเขาให้จบ

ค่ามือของเคสจะเข้า **รายได้ของฉัน** อัตโนมัติ**เมื่อแอดมินปิดเคสแล้ว** (ไม่ใช่ทันทีที่กดบันทึก — ถ้ายอดยังไม่ขึ้น ให้เช็กก่อนว่าเคสปิดหรือยัง) สิ้นเดือนเปิดหน้าเดียวกันดูสลิปเงินเดือน/สลิปโอนของตัวเอง

> หมอดูได้เฉพาะรายได้ของตัวเอง และจองคิว/ขายคอร์ส/รับเงิน/ปิดเคสไม่ได้ — งานเหล่านี้เป็นของแอดมิน/เซลส์

## BT (ผู้ช่วยหัตถการ)

![เมนูของ BT](img/03-sidebar-bt.png)

BT เห็นเมนูชุดเดียวกับหมอ

- **งานหน้าร้าน** — **OPD / หน้าห้อง**
- **บุคคล** — **ลงเวลาเข้างาน** · **ลางาน** · **รายได้ของฉัน**

**หนึ่งวันของ BT** — เปิด **OPD / หน้าห้อง** จะเห็น**คิวที่มอบหมายให้ตัวเอง รวมถึงคิวที่ยังไม่ได้ระบุตัว BT** (เผื่อหยิบงานที่ยังว่างได้) งานของ BT อยู่ในการ์ด **ขั้น BT (pre-procedure)** — หัตถการขั้นเตรียมก่อนส่งต่อให้หมอ ทำเสร็จแล้วกด **บันทึก + เสร็จขั้น BT** หมอถึงจะทำขั้นแพทย์ต่อได้ ค่ามือเข้า **รายได้ของฉัน** อัตโนมัติเมื่อแอดมินปิดเคส เช่นเดียวกับหมอ

> BT ขายคอร์ส/รับเงิน/ปิดเคสไม่ได้ และดูรายได้ได้เฉพาะของตัวเอง

## ถ้าทำรายการเกินสิทธิ์ จะเกิดอะไรขึ้น

ระบบตรวจสิทธิ์ซ้ำที่เซิร์ฟเวอร์ทุกครั้ง ตัวอย่างข้อความที่จะเจอ

| ใครลองทำอะไร | ข้อความที่ระบบตอบ |
|---|---|
| เซลส์ใส่ราคาปรับหน้างาน | ปรับราคาหน้างานได้เฉพาะ admin/เจ้าของ |
| เซลส์กดอนุมัติใบลา | เฉพาะ admin อนุมัติได้ |
| แอดมินยกเลิกใบเสร็จ / เปิดเงินเดือน | เฉพาะเจ้าของระบบเท่านั้น |
